# Repo Steward — personal deployment information

This repository hosts the public description, privacy policy and deployment terms for a personal local Repo Steward installation.

- [Application information](https://mapchronomancer.github.io/)
- [Privacy policy](https://mapchronomancer.github.io/privacy.html)
- [Deployment terms](https://mapchronomancer.github.io/terms.html)

The local tool manages owned GitHub projects and Pages publication. Its Google integration verifies site ownership, submits sitemaps and reads URL Inspection results after explicit OAuth consent.

This website provides information, not a hosted user account or an indexing guarantee. The repository contains static public pages; OAuth credentials and local application databases do not belong in this repository.
