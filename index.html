Repo Steward helps its operator manage owned GitHub repositories, publish GitHub Pages and keep search submission separate from confirmed indexing.

How Google access is used ↗

This page describes a personal local deployment. It is not a hosted account registration service.

01

Owned repositories

Review project metadata, draft content and publish files through the operator's configured GitHub account.

02

Pages and sitemap

Check public HTML and sitemap files. With explicit Google consent, verify a new Pages URL and send its sitemap to Search Console.

03

Honest search status

Read Google's URL Inspection API. A submitted sitemap is recorded as a submission; an indexed page requires a separate indexing result.

Your account, your choice

Google access starts with consent.

The integration requests Search Console access for verified sites and permission to verify new sites. Google controls the scope of that permission. Repo Steward's publication workflow selects owned projects; it does not make Google grant permission for just one repository.

Access can be revoked in Google Account connections. Revoking access stops future authorized requests after existing access tokens expire.
